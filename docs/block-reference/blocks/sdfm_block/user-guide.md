# SDFM (Sigma-Delta Filter Module) (`sdfm_block`) — User Guide

> Generated by `build_block_docs.js` on 2026-10-21.

## What it does

Sigma-Delta Filter Module for current sensing.

Interfaces with the SDFM peripheral to read phase currents for motor control loops.

## Parameters

| Parameter | Display name | Default | Options |
|---|---|---|---|
| `filterChannel` | Filter Channel | `0` | `0`, `1`, `2`, `3` |
| `osr` | Over Sampling Ratio (OSR) | `64` | — |
| `noOfCycles` | Number Of Cycles | `10` | — |

## Ports

| Port | Type |
|---|---|
| `prev` | `IO_PREV` |
| `next` | `IO_NEXT` |
| `output1` | `output32` |

## How to use

1. In SysConfig (PRU No-Code), add a **SDFM (Sigma-Delta Filter Module)** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_sdfm_read` invocation into the PRU assembly.

## Notes

- Invalid configurations are rejected by SysConfig with the validation messages listed in the [design doc](./design.md).
- Timing constants are in PRU clock cycles; confirm any `TODO`/`VERIFY` lines against your SoC TRM before flashing.
