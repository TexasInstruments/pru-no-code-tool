# Host mailbox / ring buffer (`mailbox_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

Host mailbox / ring-buffer exchange.

Emits PRU-side publish/consume skeletons over DMEM/shared-memory windows. In consume mode, output1 is the slot value and is slotBytes wide; when the ring is empty, output1 is left unwritten.

## Parameters

| Parameter | Display name | Default | Options |

## How to use

1. In SysConfig (PRU No-Code), add a **Host mailbox / ring buffer** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_mailbox_run` invocation into the PRU assembly.
