# IQMath PID Controller (`iqmath_pid_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

Proportional-Integral-Derivative (PID) controller using IQMath.

Calculates the PID output based on Setpoint and Feedback using fixed-point Q12 math via the PRU MAC broadside interface.

## Parameters

| Parameter | Display name | Default | Options |
|---|---|---|---|
| `kp` | Proportional Gain (Kp) | `1.0` | — |
| `ki` | Integral Gain (Ki) | `0.1` | — |
| `kd` | Derivative Gain (Kd) | `0.01` | — |
| `noOfCycles` | Number Of Cycles | `50` | — |

## Ports

| Port | Type |
|---|---|
| `prev` | `IO_PREV` |
| `next` | `IO_NEXT` |
| `input1` | `input32` |
| `input2` | `input32` |
| `output1` | `output32` |

## How to use

1. In SysConfig (PRU No-Code), add a **IQMath PID Controller** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_iqmath_pid` invocation into the PRU assembly.

## Notes

- Invalid configurations are rejected by SysConfig with the validation messages listed in the [design doc](./design.md).
