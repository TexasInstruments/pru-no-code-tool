# XFR2PSI / XFRDMA (PRU to PSI-L) (`xfr2psi_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

PRU to PSI-L packet streaming via XFRDMA — no memory hop.

Translates between XFR bus and PSI-L busses (SPRUIM2J 6.4.6.3.2). XID 0 is status; XID N selects PSI-L thread N. Up to 32 threads, width 64/128/256 bits. Table 6-60 broadside IDs 0x50-0x53 (four copies, RTU_PRU1/0+PRU1/0) plus shared pair 0x58/0x59 (RTU only, needs RTU_PRU_PSI_SHARE_EN).

## How to use

1. In SysConfig (PRU No-Code), add a **XFR2PSI / XFRDMA (PRU to PSI-L)** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_xfr2psi_run` invocation into the PRU assembly.
