# MAC Hardware (Multiply-Accumulate) (`mac_hw_block`) — User Guide

> Generated by `build_block_docs.js` on 2026-10-21.

## What it does

Hardware Multiply-Accumulate using PRU MAC widget.

Utilizes the PRU's internal MAC hardware to perform fast multiplication and accumulation (A * B + C).

## Parameters

| Parameter | Display name | Default | Options |
|---|---|---|---|
| `noOfCycles` | Number Of Cycles | `9` | — |

| `input2` | `input32` |
| `input3` | `input32` |
| `output1` | `output32` |

## How to use

1. In SysConfig (PRU No-Code), add a **MAC Hardware (Multiply-Accumulate)** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_mac_hw` invocation into the PRU assembly.
