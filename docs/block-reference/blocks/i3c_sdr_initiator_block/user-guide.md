# I3C SDR Initiator (ENTDAA Slice) (`i3c_sdr_initiator_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

I3C SDR open-drain Initiator (narrow slice).

Emits an I3C ENTDAA (Dynamic Address Assignment) macro-generation skeleton. Proves protocol bit-bang scaffolding for START, 0x7E+W, 0x07, Sr, and 0x7E+R; PID capture is stubbed with a dummy value. Hardware HDR/Push-Pull timing is NOT validated.

## How to use

1. In SysConfig (PRU No-Code), add a **I3C SDR Initiator (ENTDAA Slice)** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_i3c_entdaa` invocation into the PRU assembly.
