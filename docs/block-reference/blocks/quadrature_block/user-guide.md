# Quadrature encoder decoder (`quadrature_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

AB/ABZ quadrature decoder.

Emits a polling decoder with position and edge-count state in PRU registers.

## How to use

1. In SysConfig (PRU No-Code), add a **Quadrature encoder decoder** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_quadrature_run` invocation into the PRU assembly.
