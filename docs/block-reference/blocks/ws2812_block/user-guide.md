# WS2812 LED Strip (`ws2812_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

WS2812 addressable LED strip driver.

Emits precise cycle-timed bit-banging assembly for WS2812 LEDs. The 24-bit color register is sent bit 23 first in GRB packing (bits 23-16 green, bits 15-8 red, bits 7-0 blue).

## How to use

1. In SysConfig (PRU No-Code), add a **WS2812 LED Strip** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_ws2812_tx` invocation into the PRU assembly.
