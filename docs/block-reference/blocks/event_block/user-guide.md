Event / Interrupt


## Parameters

| Parameter | Display name | Default | Options |
|---|---|---|---|
| `mode` | Mode | `wait` | `wait`, `signal`, `waitThenSignal` |
| `inputEventBit` | Input Event R31 Bit | `30` | — |
| `outputEvent` | Output System Event | `16` | — |
| `clearAfterWait` | Clear Event After Wait | `true` | — |

## Ports

| Port | Type |
|---|---|
| `prev` | `PREV` |
| `next` | `NEXT` |

## How to use

1. In SysConfig (PRU No-Code), add a **Event / Interrupt** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_event_block` invocation into the PRU assembly.

## Notes

- Invalid configurations are rejected by SysConfig with the validation messages listed in the [design doc](./design.md).
- Timing constants are in PRU clock cycles; confirm any `TODO`/`VERIFY` lines against your SoC TRM before flashing.
