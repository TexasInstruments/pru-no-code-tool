# SPI ADC Sequencer (`spi_adc_sequencer_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

Sequenced SPI ADC sampling front-end.

Executes a sequence of SPI conversions with fixed deadlines and t_conv waits.

## How to use

1. In SysConfig (PRU No-Code), add a **SPI ADC Sequencer** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_spi_adc_seq` invocation into the PRU assembly.
