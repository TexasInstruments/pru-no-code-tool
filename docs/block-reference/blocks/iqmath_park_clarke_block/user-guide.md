# IQMath Park/Clarke Transform (`iqmath_park_clarke_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

Park and Clarke transforms for motor control.

Translates 3-phase current (Ia, Ib, Ic) to 2-axis orthogonal vectors (Alpha, Beta) using Clarke, and then to rotating reference frame (D, Q) using Park transform.

## Parameters

| Parameter | Display name | Default | Options |
|---|---|---|---|
| `transformType` | Transform Type | `Forward` | `Forward`, `Inverse` |
| `noOfCycles` | Number Of Cycles | `97` | — |

## How to use

1. In SysConfig (PRU No-Code), add a **IQMath Park/Clarke Transform** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_iqmath_transform` invocation into the PRU assembly.
