# Parallel Bus / Strobe (`parallel_bus_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

A7 parallel bus / strobe.

Drives or samples a CONTIGUOUS field of data pins with a single strobe pulse. Setup and hold are loop-trip counts (integer 0..65535): a delay of N trips lasts 2 + 2N PRU cycles, and 0 emits no delay at all. Behaviour change: the loops used to collapse to one cycle regardless of the configured count; the default of 2 trips now gives a 6-cycle setup and a 6-cycle hold.

## How to use

1. In SysConfig (PRU No-Code), add a **Parallel Bus / Strobe** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_parallel_bus_run` invocation into the PRU assembly.

## Notes

- Invalid configurations are rejected by SysConfig with the validation messages listed in the [design doc](./design.md).
- Timing constants are in PRU clock cycles; confirm any `TODO`/`VERIFY` lines against your SoC TRM before flashing.
