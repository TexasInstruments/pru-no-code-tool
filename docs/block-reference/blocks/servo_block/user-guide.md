# RC Servo / ESC PWM (`servo_block`) — User Guide

> Generated by `build_block_docs.js` on 2026-10-21.

## What it does

RC servo / analog-ESC PWM output.

Produces a single cycle-exact pulse and waits the remainder of the frame period.

## How to use

1. In SysConfig (PRU No-Code), add a **RC Servo / ESC PWM** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_servo_pulse` invocation into the PRU assembly.
