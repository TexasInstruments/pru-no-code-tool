# Data Splitter (`data_splitter`) — User Guide

> Generated by `build_block_docs.js` on 2026-10-21.

## What it does

Data Splitter


## Data Splitter Block

### Purpose
Extracts the lower or upper 32 bits from a 64-bit input (two consecutive registers).
Connect the output of a 64-bit block (e.g. UART RX Op in extended mode, Memory Access
with dataSize > 4) to this block's input, and select which half you need.

### Generated Assembly
**Lower 32 bits:**
```assembly
MOV  R_out, dataRegLo   ; copy lower register
```

**Upper 32 bits:**
```assembly
MOV  R_out, dataRegHi   ; copy upper register
```

### Ports
- **in64**: 64-bit data input (two consecutive registers)
- **out32**: 32-bit data output (selected half)

### Configuration
- **Split Select**: Choose `lower` (bits 31:0) or `upper` (bits 63:32)

## How to use

1. In SysConfig (PRU No-Code), add a **Data Splitter** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_data_splitter_lower` invocation into the PRU assembly.
