## How to use

1. In SysConfig (PRU No-Code), add a **Cooperative Task Scheduler** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_scheduler_block` invocation into the PRU assembly.
