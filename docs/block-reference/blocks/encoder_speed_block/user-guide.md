# Encoder Speed (IEP) (`encoder_speed_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

PRU quadrature encoder speed measurement.

Emits parameterized speed, position and direction decoder loop in PRU assembly.

## How to use

1. In SysConfig (PRU No-Code), add a **Encoder Speed (IEP)** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_encoder_speed_run` invocation into the PRU assembly.
