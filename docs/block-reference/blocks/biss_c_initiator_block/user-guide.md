# BiSS-C Initiator (`biss_c_initiator_block`) — User Guide

> Generated by `build_block_docs.js`.

## What it does

BiSS-C protocol initiator leveraging Motor Control SDK.

Interfaces with the BiSS-C encoder. It is a shift register only: clock spacing is a fixed NOP (the clock frequency is not configurable), and there is no CRC, start/ACK or timeout handling. TI pru-simulator measures an 8-cycle bit period with changing input data. Exact 5 MHz physical timing and propagation delay are not implemented.

## How to use

1. In SysConfig (PRU No-Code), add a **BiSS-C Initiator** block to your PRU core's flow.
2. Set the parameters above; wire `prev`/`next` to sequence it, and any `input`/`output` data ports to neighbouring blocks.
3. Generate — the block emits its `m_biss_c_read` invocation into the PRU assembly.
